**برّاق** منصة تعليمية ذكية تدير الصفوف، المحتوى، التقييم، والاشتراكات، وتوظّف شخصيات الذكاء الاصطناعي في رحلة الطالب. هذا المستودع هو **لوحة الإدارة التشغيلية** للمنصة: الواجهة التي يستخدمها مديرو المنصة، ومديرو المؤسسات، والمشرفون لإدارة الحسابات والمحتوى والتشغيل دون التعامل مع واجهة برمجية مباشرة.

التطبيق تطبيق ويب إنتاجي مبني على Next.js، يتحدث العربية (RTL) والإنجليزية (LTR)، ويتصل بخادم برّاق عبر طبقة وسيطة على الخادم نفسه (BFF). المتصفح لا يخاطب الـ API إلا عبر مسارات اللوحة الآمنة.

---

## 🎯 ما الذي تحلّه هذه اللوحة؟

تشغيل منصة تعليمية متعددة المؤسسات يحتاج سطحاً واحداً يوحّد:

- 👥 إدارة المستخدمين والأدوار والصلاحيات وفق ما يمنحه الخادم
- 🏫 المؤسسات والصفوف وطلبات الانضمام والدعوات
- 📚 المحتوى التعليمي، مكتبة الصف، الخطط، واختبارات المنصة
- 📝 عمل الصف اليومي: الإعلانات، الأحداث، الواجبات والتسليمات، واختبارات الصف
- 📈 متابعة أداء الطلاب ومهام الذكاء الاصطناعي ومخرجاته
- 💳 الاشتراكات، الدعم، وسجل التدقيق وصحة النظام

صلاحيات الواجهة تخفي ما لا يُسمح برؤيته؛ الخادم يبقى مصدر الحقيقة لأي عملية قراءة أو كتابة.

## ✨ أبرز القدرات

- 🔐 مصادقة بجلسة JWT داخل ملفات تعريف ارتباط `HttpOnly`، مع تجديد تلقائي عند انتهاء صلاحية رمز الوصول
- 🛡️ حماية CSRF (Double-Submit) وفحص Origin على مسارات التعديل والوكيل
- 🎫 تنقّل وRBAC حسب `permissions` و`allowed_sections` القادمة من حساب المدير
- 🏠 نظرة عامة تتبدّل حسب نطاق الحساب: منصة كاملة، مؤسسة، أو صفوف محددة
- 📊 جداول تشغيلية: بحث، تصفية، ترتيب، ترقيم صفحات، وتفاصيل دون عرض المعرّفات الداخلية
- 🤖 مركز الذكاء الاصطناعي: المهام، التغذية الراجعة، والنتائج
- 🎨 هوية برّاق بتصميم CSS مخصص (بدون Tailwind)، مع وضع فاتح وداكن
- 🐳 جاهزية نشر عبر Docker وCoolify

| 🏠 | الرئيسية | مؤشرات المنصة حسب نطاق الحساب |

| 🔑 | الصلاحيات | الأدوار ودليل الصلاحيات |

| 💚 | النظام | صحة الخدمة |

اختبارات `/quizzes` كتالوج المنصة. اختبارات صف معيّن تُدار من داخل سجل الصف.

## 🏗️ المعمارية والتقنيات

```text
المتصفح  →  /api/auth/*  و  /api/bff/*
السيرفر  →  BACKEND_API_URL  (ينتهي بـ /api/v1)
الخادم   →  Django Admin API — مصدر الصلاحيات والنطاق والبيانات
```

| | الطبقة | التقنية |
|---|---|---|
| ⚛️ | الواجهة | React 19 · Next.js 15 (App Router) |
| 🟦 | اللغة | TypeScript 5.8 |
| 🎨 | التصميم | CSS مخصص بهوية برّاق · خط Cairo |
| 🔄 | الحالة | TanStack Query |
| 🔗 | التكامل | Axios عبر مسارات المصادقة والـ BFF فقط |

عنوان الخادم الافتراضي للإنتاج:

```text
BACKEND_API_URL=https://api.baraqapp.com/api/v1
```

📄 تغطية العقود موثّقة في [`DASHBOARD_API_COVERAGE.md`](./DASHBOARD_API_COVERAGE.md).  
🧾 سجل تطوير المنتج في [`REDMI.md`](./REDMI.md).

## 🚀 التشغيل المحلي

```bash
cp .env.example .env.local
npm install
npm run dev
```

ثم افتح 🌐 `http://localhost:3000/ar/login`.

### ⚙️ متغيرات `.env.local`

| المتغير | الدور |
|---|---|
| `BACKEND_API_URL` | عنوان الباك مع `/api/v1` — من جهة السيرفر فقط |
| `API_BINDING_ENABLED` | `true` للربط الحي؛ `false` يرفض الدخول والـ BFF |
| `NEXT_PUBLIC_API_BINDING_ENABLED` | نفس العلم للعميل (يُثبَّت وقت البناء، مطلوب مع Docker) |
| `AUTH_COOKIE_SECURE` | `true` مع HTTPS في الإنتاج |

⚠️ لا تضع مفاتيح OpenAI أو خدمات الذكاء الاصطناعي في لوحة التحكم؛ تلك تخص خدمات المنصة الخلفية.

## 🔐 عقد المصادقة والبيانات

| المسار المحلي | الدور |
|---|---|
| `POST /api/auth/login` | تسجيل الدخول |
| `POST /api/auth/logout` | تسجيل الخروج |
| `GET /api/auth/session` | حالة الجلسة |
| `GET /api/auth/csrf` | رمز CSRF |
| `/api/bff/[...path]` | وكيل آمن لواجهات الإدارة |
| `GET /api/health` | صحة تطبيق اللوحة |

🔒 المتصفح لا يتصل بالباك إند مباشرة. قيم نموذج الدخول تُقرأ من `FormData` عند الإرسال حتى لا تُرسل حقول قديمة من حالة React بينما يظهر مدير كلمات المرور قيماً في الحقول.

## ✅ الجودة والنشر

```bash
npm run typecheck
npm run lint
npm run build
npm run check          # typecheck ثم البناء
node scripts/validate-dashboard.cjs
```

🐳 للنشر على Coolify: مستودع Git خاص، تطبيق Docker Compose، ربط النطاق بخدمة `dashboard` على المنفذ `3000`، وضبط `BACKEND_API_URL` وقت التشغيل. فعّل HTTPS قبل `AUTH_COOKIE_SECURE=true`. النطاق المقترح: `https://dashboard.baraqapp.com`.

قبل اعتماد إنتاج: تثبيت الحزم، `typecheck` و`build`، ربط حي مع بيئة staging، وتجربة دخول بحساب مدير حقيقي عبر `/ar/login`.
